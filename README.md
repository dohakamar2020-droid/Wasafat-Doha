# وصفات قمر

مكتبة عربية منتقاة من وصفات الشيفات على YouTube: **77 وصفة، 80 مصدر فيديو وشورت، 5 شيفات، و8 وصفات بمقادير وخطوات مكتملة**. الوصفة منفصلة عن مصدر الفيديو، والمحتوى غير المراجع يظهر كترشيح فيديو.

واجهة عربية RTL بالكريمي والزيتوني والبرتقالي، مصممة للموبايل، مع بحث عربي وفلاتر، ترشيحات تحترم الشروط، مخزون مكونات، سفرات ومشتريات، وصفات مرتبطة، اختيار أسبوعي، ووضع طبخ ودفتر تجارب.

المحتوى المنشور يقرأ من Neon Postgres عند توصيله. الإدارة تدعم إدخال المصادر وكشف التكرار والتحرير والمعاينة والنشر والأرشفة والبلاغات. الضيف يحفظ على جهازه، والحساب يضيف مزامنة منفصلة آمنة من تعارض التحديثات. صور الحسابات تستخدم Vercel Blob الخاص.

## تشغيل محلي

استخدم Node 22 ثم:

```bash
npm ci
npm run dev
```

المكتبة ووضع الضيف يعملان بدون حساب أو قاعدة بيانات. للحسابات والإدارة والبلاغات اتبع [دليل التشغيل](docs/OPERATIONS.md).

## فحوص

```bash
npm run check
npm run build
```

الاختبارات تغطي الترشيحات والمكونات والمشتريات وعلاقات الوصفات وحماية بيانات الأجهزة والمهاجرة من النسخة السابقة وترحيلات Postgres والتحديثات المشروطة. GitHub Actions يشغّلها مع بناء الإنتاج.

- [تفاصيل التنفيذ والتحقق](docs/IMPLEMENTATION.md)
- [إعداد Neon وVercel والتخزين والأدمن](docs/OPERATIONS.md)

الفيديوهات تُعرض من YouTube بالمشغّل الرسمي عند الضغط، ولا يعاد تنزيلها أو رفعها. أرقام المشاهدات هي أرقام المصدر في تاريخ الرصد؛ لا توجد تقييمات أو تجارب فريق مختلقة.
