# 🌙 وصفات قمر — Wasafat Doha

**وصفات قمر** — مكتبة عربية منتقاة بعناية: *وصفات تستاهل التجربة*.
الإنترنت مليان وصفات؛ هنا جمعنالك اللي تستاهل وقتك ومكوناتك.

> الاسم المعتمد للمشروع في كل العناوين والشعار والواجهات: **وصفات قمر**

## المحتوى الأولي
- **80 فيديو وشورت** (77 وصفة — 3 وصفات لها شرح كامل + شورت منفصل) من القنوات الأصلية.
- الفترة: 22 أكتوبر 2024 → 22 أكتوبر 2026، وأرقام المشاهدات تقريبية وقت المراجعة.
- الشيفات: نادية السيد (23) · هبة أبو الخير (24) · عبير الصغير (21) · شيف عمر (8) · أبو جوليا (4).
- كل الوصفات حاليًا بحالة **«ترشيح فيديو»**: المقادير والخطوات عند صاحبها في الفيديو الأصلي، ولا نعرض أوقات/مقادير غير مراجعة.

## الصفحات والمسارات
| المسار | الصفحة |
|---|---|
| `/` | الرئيسية (هيرو، على مزاجك، ابدأ باللقطات دي، عندك إيه، شورتس، سفر جاهزة، الشيفات) |
| `/discover` | الاكتشاف: بحث عربي بمرادفات + فلاتر (النوع، الشيف، القوام، الاحتياج، المكوّن، فيديو/شورت) |
| `/recipes/[slug]` | صفحة الوصفة: المشاهدة، ليه اخترناها، المصدر، جهّز دول أول، ناقصك إيه، ملاحظاتي |
| `/recipes/[slug]/cook` | وضع الطبخ: فيديو كبير، تجهيز، مؤقتات محفوظة، ملاحظات، تسجيل التجربة |
| `/watch/[id]` | مشاهدة الشورتس مع تنقّل تالي/سابق |
| `/pick` | **رشحلي 3** — 3 أسئلة و3 ترشيحات بأسباب، مع تبديل اختيار واحد |
| `/ingredients` | **عندك إيه؟** — مطابقة مكونات (عندك / ناقصك واحد) + استبعاد مكوّن |
| `/collections` + `/collections/[slug]` | مجموعات تحريرية (البطاطس في حتة تانية، حلويات التلاجة…) |
| `/creators` + `/creators/[slug]` | الشيفات ووصفاتهم المنتقاة |
| `/kitchen` + `saved` / `shopping` / `attempts` | **مطبخي** — الحفظ والخطط والتجارب والمشتريات (localStorage على الجهاز) |
| `/about` | فكرة وصفات قمر ومنهج الانتقاء |
| `/admin` | لوحة إدارة محلية تجريبية: إضافة رابط + كشف تكرار + مراحل المحتوى |

## التقنية
Next.js (App Router) + TypeScript، بيانات seed في `lib/data.ts` (نموذج يفصل الوصفة `Recipe` عن مصدر الفيديو `VideoSource`)، تضمين يوتيوب الرسمي عند الطلب، وتصميم زجاجي دافئ (كريمي/زيتوني/برتقالي محروق) بخطوط Alexandria + IBM Plex Sans Arabic. جاهز للنشر على Vercel.

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
```

## النشر على Vercel 🚀
المشروع مهيأ للنشر على Vercel مباشرة من الريبو:

1. من Vercel: **Add New → Project** واختار ريبو `وصفات قمر` (Wasafat-Doha).
2. **Root Directory:** خليه فاضي (جذر الريبو نفسه) — المشروع مش monorepo.
3. الإعدادات بتتقرأ تلقائيًا من `vercel.json`:
   - Framework: `nextjs`
   - Install Command: `npm ci` (من `package-lock.json`)
   - Build Command: `npm run build`
   - Node.js: `22.x` (من `engines` في `package.json` وملف `.nvmrc`)
   - Region: `fra1` (فرانكفورت — الأقرب لزوار مصر والمنطقة)
4. مش محتاج أي Environment Variables في النسخة الحالية.

تم التحقق محليًا بنفس خطوات Vercel بالظبط: `npm ci` من غير `node_modules` ثم `npm run build` — النتيجة: **148 صفحة** (رئيسية + 77 وصفة + شورتس + مجموعات + شيفات) من غير أخطاء.
