- ✅ **المرحلة 1-2:** الهوية والتصميم، نموذج الوصفة/المصدر، الاستيراد، الرئيسية والاكتشاف والبحث العربي والفلاتر، الشيفات والمجموعات.
- ✅ **المرحلة 3:** صفحة وصفة عملية + أول دفعة **وصفات مكتملة**: 8 وصفات رُوجعت يدويًا (مقادير من وصف القناة الرسمية وخطوات من شرح الفيديو نفسه)، وبقيت الـ69 «ترشيح فيديو» بوضوح لحد ما تتراجع.
- ✅ **المرحلة 4:** قاعدة بيانات Neon + Drizzle، حسابات ومزامنة «مطبخي» (حفظ/خطط/ملاحظات/مشتريات/تجارب)، وضع طبخ بخطوات للوصفات المكتملة.
- ✅ **المرحلة 5:** رشحلي 3، عندك إيه؟، قريب منها بطعم مختلف، مقارنة وصفات `/compare`، تكوين سفرة `/meals/[slug]` بمشتريات مجمعة ومشاركة برابط.
- ✅ **المرحلة 6:** PWA قابل للتثبيت (manifest + Service Worker + أوفلاين للصفحات المزارة)، sitemap/robots، صفحات الخصوصية والتواصل والإبلاغ عن مصدر، مجموعات «مزاج الليلة»، و«لقطة الأسبوع».

## الوصفات المكتملة (الدفعة الأولى — مراجعة يدوية موثقة)
خلية السينابون والكنافة بالقشطة والنجرسكو (هبة أبو الخير) · الكبدة الإسكندراني وقدرة قادر ومكرونة بينك صوص والتيراميسو الإيطالي وكبسة إلهام (نادية السيد).
كل واحدة فيها: مقادير مجمعة بحسب الجزء مع تكبير حصص ×1/×2/×3 (للكميات الرقمية بس)، خطوات بعلامات نتيجة وأوقات من الفيديو فقط، نقطة النجاح والأخطاء الشائعة، وملحوظة مراجعة بمصدر كل معلومة. أي وصفة بلا مراجعة لا نعرض لها مقادير أو أوقات مخترعة.

## قاعدة البيانات والحسابات (Neon + Drizzle)
المخطط في `lib/db/schema.ts` (13 جدول: مستخدمين، شيفات، وصفات، مصادر فيديو، مقادير، خطوات، مراجعات، مجموعات، حفظ، ملاحظات، مشتريات، تجارب)، والترحيلات في `drizzle/`.

```bash
cp .env.example .env.local   # وحط DATABASE_URL / DATABASE_URL_POOLED / AUTH_SECRET
npm run db:push              # إنشاء الجداول (أو طبّق drizzle/*.sql)
npm run db:seed              # بذر المكتبة كلها من lib/data.ts + lib/reviewed.ts
```

- من غير `DATABASE_URL`: الموقع بيشتغل كامل بالبيانات المحلية، والحساب بيرد برسالة واضحة إن قاعدة البيانات مش مهيأة.
- الضيف: الحفظ على جهازه (localStorage). مع تسجيل الدخول: بتتدمج حالة الجهاز مع الحساب (من غير تكرار) وبتتزامن بعد كده تلقائيًا مع `/api/kitchen`.
- كلمات السر bcrypt، والجلسات JWT في كوكي httpOnly موقع بـ `AUTH_SECRET`.
- لوحة `/admin` فيها قسم قاعدة بيانات للأدمن بس (`ADMIN_EMAIL` أو `users.is_admin`): إضافة مصدر مع كشف تكرار بالـ ytId، وتحديث مشاهدات يوتيوب عند توفر `YOUTUBE_API_KEY`.

## التشغيل والنشر
```bash
npm install
npm run dev     # تطوير
npm run build   # بيلد إنتاج (اتحقق: 170 صفحة)
```
النشر على Vercel: Root Directory = جذر الريبو، والإعدادات من `vercel.json` تلقائيًا، مع إضافة متغيرات البيئة (`DATABASE_URL`, `DATABASE_URL_POOLED`, `AUTH_SECRET`, واختياريًا `ADMIN_EMAIL`, `YOUTUBE_API_KEY`) في إعدادات المشروع على Vercel — **متحطش القيم الحقيقية في الريبو أبدًا**.
